# Coupled-dynamics computing pilot

Jason Duran Dutton leads this research. Codex assisted with design, code, execution,
source review and drafting. Status: **Exploratory / Not Promoted**.

Start with [research brief and candid results](RESEARCH_BRIEF.md), then the
[frozen initial protocol](PROTOCOL.md) and [existing-code inventory](CODE_INVENTORY.md).
Run `python benchmark.py` and `python verify.py` with Python and NumPy.
The original run environment and all seeds/repeats are in results.json. Timings vary.

All 120 main instances met the accuracy target. Simulated damped dynamics were slower
than both conventional baselines. No physical energy or data-center reduction is shown.
The protocol's seed-prose typo is corrected in the brief without modifying its frozen hash.
Source snapshots are text/version records, not complete manuscript build packages.
