## Reproduce

Use the pinned repository version of the preceding sibling directory `../fixed-charge-stability`. Generate its backgrounds first:

```
python ../fixed-charge-stability/fixed_charge.py
python ../fixed-charge-stability/conditional_observables.py
python candidate_checks.py
python radial_dynamics.py
python check_schur.py
python observational_check.py
```

Set OPENBLAS_NUM_THREADS=1 and OMP_NUM_THREADS=1 before starting Python for predictable dense linear algebra runtime. Python 3.14.7, NumPy 2.5.2 and SciPy 1.18.1 were used. Dense matrices in the largest energy calculation require substantial memory; this is an explicit finite-grid computation, not a hidden simulation of the full continuum. The first unshifted iterative energy eigensolver attempt was interrupted for slow convergence and replaced by the direct solve of the same matrix; no partial iterative eigenvalues enter the findings.

`PROTOCOL.md` was written before this checkpoint's runs. Spectrum storage was changed after the run from inline JSON to generated CSVs without recalculating or discarding eigenvalues. The CSVs in the download preserve every computed eigenvalue; the JSON records their normalized text hashes. Package hashes use UTF-8/LF normalization; source archive hashes retain their original byte convention.

Read the cited primary sources for conventional background and measured constants; they do not independently validate this calculation.
